Contents
- 8 Polyart character skeletal meshes exported as FBX 2018 from Unreal Engine 5.7.
- albedo.tga: shared BasecolorDefault_TEX texture.
- export-report.json: Unreal export results.
- verification.json: import check using this project's Assimp DLL.
- Animations/: 140 animation-only FBX files, grouped by character.
  Includes the original Mushroom AngryVersion and SmileVersion subfolders.
  See Animations/export-report.json for exact source assets and skeletons.
  See Animations/verification.json for duration and bone-channel verification.

This is an asset-only addition. No enemy, scene, gameplay or project code is changed.
The characters are not yet selected or drawn by CEnemy.
Animation sequences are included separately in Animations/. Unreal materials
are not included in this export. The character FBX files are unchanged.
The original assets and animations remain in the local Unreal source project.

Future integration needs model selection, texture assignment, orientation/scale
adjustment and, if required, skeletal animation support. TestModel currently
renders static meshes. Merely adding these files does not enable animations.
