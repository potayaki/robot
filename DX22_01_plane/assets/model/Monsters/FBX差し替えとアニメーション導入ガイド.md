## まず、今どこまでできている？

**キャラと動きのファイルは、プロジェクトに入っています。**
**それを敵として表示・再生するコードは、まだ追加していません。**

| 用意したもの | 状態 |
| --- | --- |
| キャラのモデル8種類 | 追加済み |
| キャラの色を付ける画像 | 追加済み |
| 歩行・待機・攻撃などの動き140本 | 追加済み |

今回は素材の追加だけなので、ゲーム内の敵は今までどおりです。

## 1. ファイルはどこにある？

プロジェクトの次のフォルダーです。

```text
DX22_01_plane/assets/model/MonsterForSurvivalGame/
```

スライムを使う場合は、次の3つを使います。

```text
Slime.fbx           ← スライムの形と骨格
albedo.tga          ← キャラの色を付ける画像
Animations/Slime/   ← スライムの動きが入ったフォルダー
```

**「体」と「動き」は別ファイルです。**
`Slime.fbx` だけ読み込んでも、歩いたり攻撃したりはしません。

## 2. スライムを敵にしたいときは？

今の敵は `CEnemy.cpp` で立方体（`TestCube`）を表示しています。
将来、次の変更をします。

1. 立方体の代わりに、FBXモデルを表示するオブジェクトを使う。
2. 読み込むモデルを `Slime.fbx` にする。
3. 色の画像 `albedo.tga` を割り当てる。
4. 敵の位置・向きに合わせて表示し、大きさと足元の高さを調整する。

既存の `TestModel` に静的モデルを読み込む機能があります。
ただし、**`CEnemy.cpp` のファイル名を1か所変えるだけで完成する状態ではありません。**
立方体の描画をモデルの描画に置き換える必要があります。

最初は「動かないスライムを正しい見た目で表示する」ところまで確認します。

## 3. 歩行や攻撃を付けるには？

### ① 動きのファイルを選ぶ

`Animations/Slime/` を見て、用途に合うFBXを選びます。

| ファイル名に含まれる言葉 | 動きの目安 |
| --- | --- |
| Idle | 待機 |
| Walk / Run | 歩行・走行 |
| Attack | 攻撃 |
| GetHit | 被弾 |
| Die | 死亡 |

収録されている種類や名前はキャラによって違います。
**スライムにはスライム用の動きを使ってください。**

### ② 再生するコードを用意する

必要なのは、次の処理です。

```text
キャラの骨格と、動きのデータを読み込む
              ↓
再生時間に合わせて、骨格の位置や角度を計算する
              ↓
骨格に合わせて、キャラの体を変形させて描く
```

この「骨格に合わせて体を変形させる処理」をスキニングと呼びます。
今の `TestModel` は静的モデル用なので、この処理を追加する必要があります。

**この再生処理ができれば、用意した歩行・攻撃などのデータを使って動かせます。**

### ③ 敵の行動とつなぐ

`CEnemy.cpp` の行動に合わせて、再生する動きを切り替えます。

| 敵がしていること | 再生する動き |
| --- | --- |
| 止まっている | 待機を繰り返す |
| プレイヤーへ移動している | 歩行を繰り返す |
| 攻撃する | 攻撃を1回再生する |

攻撃のダメージが入る瞬間も合わせるなら、攻撃アニメーションの時刻と連携させます。
死亡の動きを最後まで見せるなら、再生が終わってから敵を消すようにします。
これらの変更も、今回は行っていません。

## 4. 別のキャラに変えたいときは？

表示・再生の仕組みができた後に、**モデルと動きの両方**を変更します。

```text
スライムにする
  モデル：Slime.fbx
  動き：Animations/Slime/ 内のFBX

サボテンにする
  モデル：Cactus.fbx
  動き：Animations/Cactus/ 内のFBX
```

今回の8キャラは色の画像 `albedo.tga` を共有します。
キャラを変えたら、大きさ・向き・足元の位置も確認してください。

## 5. 今後、新しい動きを追加したいときは？

1. Unreal Engineで、そのキャラに対応するアニメーションを選ぶ。
2. 右クリック → **Asset Actions → Export** からFBXで書き出す。
3. 今回の素材に合わせるならFBX 2018形式にする。
4. `Animations/キャラ名/` に入れる。
5. 再生コード側で、そのファイルを読み込み、「攻撃用」などの用途を指定する。

**フォルダーに入れるだけでは自動で使われません。**
再生するファイルをコードや、今後作る設定ファイルで指定する必要があります。

※今回追加した140本は、書き出し直す必要はありません。
※元のUnreal素材は `C:\work\dan\Content\MonsterForSurvivalGame` にあります。

## 6. 実装を進めるなら、この順番

1. スライム1体を静止表示する。
2. 歩行を繰り返し再生できるようにする。
3. 待機・歩行・攻撃を切り替えられるようにする。
4. 既存の敵の処理につなぐ。

素材はAssimpで読み込み確認済みで、動きのボーン名も対応モデルと一致しています。
ゲーム内での見た目や動きの確認は、再生処理を実装してから行います。
