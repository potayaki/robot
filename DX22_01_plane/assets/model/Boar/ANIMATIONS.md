# Boarの使用データ

ゲームでは `Boar.glb` を使用します。PNGテクスチャ・骨格・アニメーションが内蔵されています。
同梱の `Boar.fbx` は残していますが、ゲームからは読みません。

元データは `Take 001` という1本の24fpsアニメーションです。

| 用途 | フレーム区間 |
| --- | --- |
| 待機 | 0〜29 |
| 予備動作 | 30〜44 |
| 突進 | 44〜50 |
| 突進後の戻り | 50〜59 |
| 死亡 | 60〜89（最後の姿勢で停止） |
| 走行 | 90〜119（ループ） |

移動・予測線・当たり判定を一致させるため、生存中は素材内のHipsのXZ移動を取り除き、
移動距離は敵AIで管理します。死亡時は元の倒れ込みと後方移動を再生します。

突進開始距離は `CBoarEnemy.h` の `m_chargeStartRange`、速度・予備動作時間・突進距離は
`BoarCharge.h` のメンバ変数で調整します。Debugの「Skill Debug → Boarの確認」から、
出現・近くの個体の調整・ダメージ・死亡動作も確認できます。
