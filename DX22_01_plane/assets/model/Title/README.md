# タイトル用ジオラマ

`TitleScene.cpp` がこのフォルダのモデルを読み込み、発砲するPlayerロボットを5種類・計6体のEnemyが取り囲む戦闘ジオラマを描画します。

- 足場: `floating-island`。横幅20、縦方向0.43倍に整えています。
- 岩・植物: `stylizednaturelite_fbx`。岩は大小を混ぜ、二つの瓦礫の山に配置しています。
- 草: `grass_patch_3_lods`。ノード変換後の最も詳細なメッシュ1個だけを使い、LODを重ねません。
- 木片: 同梱の `SM_Branch_01.fbx`。
- 金属片: `urban_shanty_town_sheet_metal_corrugated_03_xmufdce_low`。

中央のPlayerは腰をひねった射撃姿勢で、両銃の銃口に発砲の光を固定しています。鳥型ドローン2体とゴーストが空中から、イノシシと赤いスライム、自爆キノコが地上から迫ります。鳥・スライム・キノコにはスムーズシェーディングを適用しています。地上の配置は島の三角形に合わせています。
足場、小物、全フィギュア、射撃エフェクトは共通の行列で180秒に1周回転します。展示台を見るカメラと照明は固定です。
展示部分で左ボタンを押している間は自動回転が止まり、左にドラッグすると上から見て時計回り、右にドラッグすると反時計回りに回せます。ボタンを離すと、その角度から自動回転が再開します。画面下部の「ゲーム開始」の下に「設定」「ゲームルール」「ゲーム終了」が並びます。

配置・サイズは `Diorama` コンストラクタの `place(...)` と `clumps`、回転速度は `TitleScene::Update()`、
視点と画面内の大きさは `Diorama::Draw()` で調整できます。
射撃姿勢と銃口の位置は `TitleRobotFigure.cpp`、敵の種類と配置は `TitleEnemyFigures.cpp` です。展示台の地表は `shader/titleGroundPS.hlsl` で砂利と草を混ぜています。照明と葉の透過抜きは `shader/titleDioramaPS.hlsl`、背景は `shader/titleBackdropPS.hlsl` です。
固定照明からロボット・敵・岩などの深度を描き、回転中もそれぞれの形に沿った影を地面に落とします。

FBXの外部画像パスに依存せず、配布されたBaseMap / Albedoを明示的に割り当てます。
`dirty-stones-pile` は高密度のため、`landmine` は今回の構成に不要なため読み込みません。
元のモデル・画像は変更していません。
