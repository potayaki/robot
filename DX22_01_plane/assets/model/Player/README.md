# プレイヤー用ロボット

`Retro_UnderWaterAssets_Freebies_FBX/Mech` の素材をこのフォルダへコピーして使用しています。
本体の `SK_ISO_Mech.fbx` は `Player.fbx` に名前を変更しています。

## 操作とアニメーション

| 操作 | 使用するアニメーション |
| --- | --- |
| 停止 | `A_ISO_Mech_Idle_01.fbx` |
| 脚の正面へ移動 | `A_ISO_Mech_WalkForward_01.fbx` |
| 脚の後方へ移動 | `A_ISO_Mech_WalkBackward_01.fbx` |
| 脚の左側へ移動 | `A_ISO_Mech_Walk_L_01.fbx` |
| 脚の右側へ移動 | `A_ISO_Mech_Walk_R_01.fbx` |

上半身と武器だけがカーソルの照準位置を向き、下半身はゲーム開始時の向きを保ちます。
左右だけでなく上下にも動くため、画面右上を狙えば右上を向きます。クリックしていない間も追従します。
照準位置は通常弾と共通で、カーソル下の敵・地面、何もなければ遠方を目標にします。
WASDの移動はカメラ基準のまま、歩行アニメーションは脚の向きに対する実際の移動方向で選びます。
例えば、カメラを右へ90度回してWで進むと、脚側は右移動のアニメーションになります。
斜め移動では前後・左右のうち移動量の大きい方向を選びます。
方向を切り替えたときは0.15秒で姿勢を補間し、回転にはSlerpを使います。
再生時間は `GameTime::DeltaSeconds()` で進めるため、FPSによらず同じ速度です。
移動速度のスキルに合わせて歩行の再生速度も上がります。
壁に止められた場合や空中では待機アニメーションを使います。

Debugビルドの `Skill Debug → ロボットのアニメーション → Animation preview` で、
移動せずに各モーションを確認できます。`Automatic` で通常操作に戻ります。
ゲームを一時停止するとアニメーションも停止します。

## HPが0になったときの分解

死亡直前の歩行・照準の姿勢から、胴体・武器・脚など30個の部品へ分解します。
部品は外側と上方向へ飛び、回転しながら重力で落下します。
地面で小さく跳ねた後は、その場に残骸として残ります。
HPが0のままでも再び飛び散ることはありません。

`Skill Debug → ロボットのアニメーション` の「死亡演出を確認（HP 0）」で確認できます。
「全回復して復帰」やHPスライダーでHPを戻すと、残骸を片付けて元の機体へ復帰します。
一時停止中は破片も止まるため、動きを確認するときは「ゲーム一時停止」を解除してください。

`RobotDebris.cpp` の `HorizontalSpeed`・`UpwardSpeed` が飛び散る速さ、
`Gravity` が落下の強さ、`Bounce` が地面での跳ね返りの強さです。
速度・重力・回転は秒単位で計算しています。
関節をまたぐ三角形はまとめて1つの部品へ入れ、分離した骨に引っ張られて面が伸びるのを防ぎます。
破片は表示用で、敵への攻撃判定はありません。
分解前後の形状・接地・30fps/120fps・復帰の確認は `tests/RobotDebrisTests.cpp` にあります。

## 大きさ・描画の調整

- `PlayerRobotModel.cpp` の `RobotScale = 0.025f` が表示倍率です。高さ約20、脚を含む幅約27にしています。
- 素材の足元がY=0なので、表示位置をプレイヤー中心から当たり判定の半径分だけ下げています。
- 素材の正面は-Zのため、描画時にY軸へ180度回してゲームの正面と合わせています。
- FBX内のテクスチャ参照先が配布画像名と異なるため、`Textures/T_Mech_Base_Color.png` を直接読み込みます。
- FBX内にあるLOD0・LOD1を重ねて描かず、詳細版のLOD0だけを描きます。

`RobotAnimationRig` が骨格と別ファイルのアニメーションを読み込み、
`PlayerRobotModel` と `shader/playerRobotVS.hlsl` が骨の動きを頂点へ反映します。
この素材は各頂点が1本の骨に固定されているため、その構造に合わせた専用の実装です。
他のモデルを使う場合は、骨名・LOD名・頂点のウェイト構造を確認してください。

`CPlayer::TryGetAimTarget()` で上半身と通常弾の照準位置を共通に計算します。
`m_lowerBodyYaw` が脚側の固定角度、`m_Rotation.y` が照準の水平角度、`m_upperBodyPitch` が仰角です。
`RobotAnimationRig::ApplyUpperBodyAim()` で、上下の角度と脚に対する水平角度の差を `Top_M` と子の骨に適用しています。
骨のローカル軸ではなくモデル空間で上下・左右の回転を作り、上半身の関節を中心に動かします。
脚の枝や歩行アニメーションの元の姿勢には、照準の回転を加えません。
